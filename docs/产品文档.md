# BrandNut CEO Coach - 产品文档

## 产品概述

**BrandNut CEO Coach** 是一个专为企业高管和决策者设计的 AI 对话教练助手。通过集成 Dify.ai 的先进对话能力，结合企业级组织管理功能，为用户提供个性化的战略决策支持和业务指导。

## 核心价值主张

### 🎯 精准定位
- **目标用户**：企业 CEO、高管团队、决策者
- **核心痛点**：战略决策缺乏参考、团队管理困难、创新瓶颈
- **解决方案**：基于 71 个精选 CEO 问题库的 AI 对话指导

### 💡 产品特色
1. **智能问题引导** - 内置 71 个高频 CEO 关注问题，覆盖战略、管理、创新等维度
2. **多租户企业架构** - 支持多组织管理，可定制不同企业的 AI 配置
3. **实时流式对话** - 基于 SSE 的流畅对话体验，支持工作流状态显示
4. **文档上传分析** - 支持 PDF、Word、Excel 等多格式文档上传，提供基于企业数据的智能分析
5. **对话历史管理** - 完整的对话记录，支持创建、切换、删除对话会话

## 用户体验流程

### 新用户引导
1. **首次访问** → 显示使用教程弹窗
2. **问题推荐** → 展示 3 个随机 CEO 问题
3. **快速开始** → 点击问题或自由提问

### 对话交互
1. **输入问题** → 文本输入 + 文档附件上传
2. **AI 处理** → 显示工作流状态（正在思考、正在检索等）
3. **流式输出** → 实时显示 AI 回复过程
4. **后续操作** → 继续对话、新建对话、查看历史

### 组织管理
1. **用户认证** → JWT Token 认证机制
2. **组织切换** → 支持用户在多个组织中切换
3. **权限管理** → 管理员/成员角色权限控制

## 技术特色

### 性能优化
- **流式响应**：基于 SSE 的实时数据流，减少等待时间
- **连接池管理**：PostgreSQL 连接池优化，支持高并发访问
- **前端优化**：Next.js 15 + React 19，支持服务端渲染和客户端缓存

### 安全保障
- **身份认证**：基于 NextAuth.js v5 的 JWT 认证
- **数据隔离**：多租户架构确保企业间数据完全隔离
- **权限控制**：细粒度的组织级权限管理

### 可扩展性
- **微服务架构**：API 路由模块化，便于功能扩展
- **配置化部署**：支持环境变量配置，适应不同部署环境
- **插件机制**：支持自定义 Mermaid 渲染和文件上传扩展
